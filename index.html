AI Chest X-ray Disease Detection

Multi-Label Chest X-ray Classification Using Deep Learning

Powered by DenseNet121

About the Project

This project uses a pretrained DenseNet121 deep learning model to identify six selected labels from chest X-ray images. It is developed using the NIH ChestX-ray14 dataset.

Predicted Labels

Atelectasis Cardiomegaly Effusion Edema Consolidation No Finding

Model Performance

Macro F1 Score: 0.3340

Micro F1 Score: 0.4209

Exact Match Accuracy: 0.2632

Hamming Accuracy: 0.7690
